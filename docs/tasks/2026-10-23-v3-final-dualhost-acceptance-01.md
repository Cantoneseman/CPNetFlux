# V3-FINAL-DUALHOST-ACCEPTANCE-01

## 任务范围

在两台阿里云服务器上用同一份 CPNetFlux V3 构建产物完成真实跨机上传和下载，验证控制连接、数据连接、TLS、校验、远端落盘和结果摘要在实际网络中的闭环。

## 非目标

- 不修改系统网络、云安全组或物理网卡配置。
- 不停止或覆盖上海现有 2121 服务。
- 不把本轮跨机验收结果当作 GridFTP 性能结论。
- 不引入 V1/V2 运行逻辑。

## 输入基线

- 深圳分支：codex/V3-DESKTOP-NETWORK-BINDING-01
- 输入提交：d4ab4b7b3af378a105ce360fcbd4e0c02538475c
- 构建产物：summary CRC reuse 阶段的 Release 二进制
- 两端源码归档和三项客户端/服务端二进制 SHA 已在前一阶段核对一致。

## 验收标准

1. 深圳客户端能够通过上海公网地址建立 CPNetFlux V3 TLS 控制和数据连接。
2. 上传后的远端文件集合与源端逐文件 SHA-256 一致。
3. 上海客户端从深圳服务端下载后，下载文件集合与源端逐文件 SHA-256 一致。
4. JSON 摘要明确记录成功、校验和实际传输模式；失败时能给出可诊断错误。
5. 记录网络端口、构建 SHA、数据集摘要、命令和输出证据。

## 受影响文件

- 本任务文档及其 result 文档。
- 若跨机验收暴露协议或实现缺陷，仅修改深圳源码、测试和对应文档；无缺陷则不改生产代码。
