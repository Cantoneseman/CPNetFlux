## Scope

This round skips RDMA resource pool, CQ, RQ/SQ, and verbs data-plane optimization. It focuses on the CPNetFlux V3 three-stage path: source read/frame checksum, network transfer, and receiver checksum/write/commit. First measure the existing bounded payload pipeline at fixed depths, including queue watermark, producer/consumer waits, CPU, and stage wall time, using a fixed-commit in-memory RDMA comparison. After attribution, implement only one main pipeline factor. Preserve ordering, checksum, range writes, manifest, recovery, and atomic commit semantics.
