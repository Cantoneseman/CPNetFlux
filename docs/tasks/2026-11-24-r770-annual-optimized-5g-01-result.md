# R770 优化后 5 GiB 年度对比｜第二阶段停测报告

2026-11-24。两组单文件规模统一为 **5 GiB（5,368,709,120 字节）**。R770-2 → R770-1 主对比完成 5 对，判定 PASS。R770-1 → R770-2 完成 4 对，第 5 对触发网卡硬门，判定 INCOMPLETE / ABORTED。用同一份不可压缩文件和普通 tmpfs，不把其他尺寸的结果纳入本轮。

## 主对比

| 方向 | 完整有效配对 | CPNetFlux 中位 Gbps / 秒 | GridFTP 中位 Gbps / 秒 | 速率中位数之比 |
| --- | ---: | ---: | ---: | ---: |
| R770-2 → R770-1 | 5/5 | 35.39 / 1.214 | 17.26 / 2.489 | 2.05× |
| R770-1 → R770-2 | 4/5 | 34.75 / 1.236 | 17.32 / 2.480 | 2.01× |

正向的 CPNetFlux 范围为 34.38–36.23 Gbps，CV 2.09%，GridFTP 为 16.71–18.41 Gbps，CV 3.59%。反向四对分别为 34.40–36.95 Gbps、CV 2.87%，以及 16.73–17.97 Gbps、CV 2.55%。CV 为总体标准差与平均速率的比值。反向第 5 对的 GridFTP 样本本身通过，因对应 CPNetFlux 样本拒收，该对的两个速率均不进入配对统计。主对比保留 19 个通过门槛的样本及 1 个拒收样本。

反向 10 号 CPNetFlux 样本完整收到文件，5,120 个分块、外部 SHA-256 和协议终态均通过。R770-2 的 rx_missed_errors 和 rx_out_of_buffer 分别从 0 升至 1,332，样本拒收。R770-1 发送端同期整机 TCP 重传增加 1,335，双端无新增换出或全局 full 内存停顿。本轮未做流级归因。原始文件为 main-formal-r1-10-mmap.json，包含两个时间边界和原计数。

CPNetFlux 用四流 V3 明文 TCP 下载、inline mmap、256 KiB 帧、1 MiB 接收缓冲请求、CRC32C、verified_chunks、每 16 块 checkpoint、每流 1.5 GB/s 限速和关闭压缩。GridFTP 用真实 GSI 控制认证和明文文件数据、四流 MODE E、1 MiB TCP 缓冲请求及 256 KiB block。两端通过 eno17095np0 的 192.168.100.1/.2 直连传数据。CPNetFlux 由接收端客户端发起下载，GridFTP 由 R770-1 编排双端第三方传输。速率为成功文件字节数除以客户端启动到退出的时间，含建连、传输与协议收尾，外部 SHA 另外计时。通过的完整配对中，两端可用内存最低约 22.61/23.65 GiB。主机 CPU 与进程 CPU 是不同口径。主机指标和逐对差值见 verified-summary.json。

## 安全组停止时的状态

在收到停止指令前，旧 run 已完成五种模式各一次 5 GiB 准入，并进入正式组。停止指令到达时，首个 GSI 明文正式样本已通过，第二项 CPNetFlux TLS 被中断，无客户端终态回执。这两条样本保留在旧窗口。独立安全 run 尚未启动。

| R770-2 → R770-1 | 有效准入数 | 准入耗时 / Gbps | 旧窗口正式已通过 / 已中断 |
| --- | ---: | ---: | ---: |
| GridFTP 临时匿名明文 | 1 | 2.341 秒 / 18.34 | 0 / 0 |
| GridFTP GSI 明文 | 1 | 2.511 秒 / 17.11 | 1 / 0 |
| GridFTP GSI 私密数据 | 1 | 3.701 秒 / 11.61 | 0 / 0 |
| CPNetFlux token 明文 | 1 | 6.661 秒 / 6.45 | 0 / 0 |
| CPNetFlux token + 控制与数据 TLS | 1 | 6.144 秒 / 6.99 | 0 / 1 |

上述单次准入只反映各配置在该次传输通过门槛。私密 GridFTP 的两个服务端均确认 PROT P，CPNetFlux 摘要同时确认控制和文件数据使用 TLS。本轮新 GSI proxy 为 RFC 3820，签发时剩余 21,600 秒，通过双端证书、临时 DN 映射和双向 8 MiB 认证 smoke。最后一次 GSI 正式样本中还剩 21,227 秒。旧凭据收尾时已删除，后续独立 run 需要重新签发并验明有效期、认证及数据模式。

## 现场和证据

临时服务、源和目标、实验凭据均已清理。R770-2 自动清理因上传留下的顶层清单文件名校验失败，核对目录标记、属主及精确文件名后清理了该 477 字节清单，随后确认临时监听和凭据目录为空。原 2121 服务身份、直连路由和双端 RX/TX 1024/1024 核对一致。

清理后按预定至少 6 秒的窗口观察 6.35 秒。R770-1 漏包和缓冲不足计数均保持 2,097，R770-2 两项均保持 1,332，其余所采网卡与 HCA 错误增量为零。两端可用内存约 27.77/28.77 GiB，tmpfs 各可用 16,382,611,456 字节，无新增换出或 full 内存压力。主机现场满足独立安全 run 的空载和资源前提，凭据准入和启动待下一条执行指令。
