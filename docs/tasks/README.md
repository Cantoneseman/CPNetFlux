# Codex 任务目录

新角色先从 `docs/coordination/START_HERE.md` 接手。总指挥使用 `docs/coordination/TASK_TEMPLATE.md` 派单，并在 `docs/coordination/BOARD.md` 管理状态。角色 prompt 与初始化回执在 coordination 目录；这里保留具体开发任务规格。

每个长期任务使用一个单独的任务文件，文件名格式为 `YYYY-MM-DD-简短名称.md`。任务文件只记录范围、输入、验收和交接，不复制大段代码或原始日志。

开始任务前阅读：

1. `AGENTS.md`；
2. `docs/AI_COLLABORATION.md`；
3. `docs/RESEARCH_BASELINE.md`；
4. 最近的 `docs/DECISIONS/`；
5. 任务文件中列出的具体源码和测试。

任务结束时追加提交号、验证命令、结果目录、已知限制和下一步。未完成的任务不能写成“完成”，应明确阻塞原因和可继续的入口。
