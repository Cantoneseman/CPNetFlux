## 任务范围

1. 把 V2 persistent tree 的可靠事务补齐：FILE_BEGIN/FILE_END 使用请求的 checksum 算法；接收端验证后才提交，失败留下统一 checkpoint/manifest 状态。
2. 让 V2 读取并继续现有 tree manifest 与 per-file checkpoint；resume 至少保证已提交文件跳过、未提交文件可安全重试，身份变化、旧 manifest、目标冲突和断线都拒绝或保留 recoverable 状态。
3. 将已有 `FramedDataSocket` TLS 接入 V2 数据通道；控制面在 payload 前协商 checksum、resume、data TLS，能力或配置不一致时结构化拒绝。
4. 默认 tree 路径使用 V2；V1 不再作为 V2 能力不足时的隐式回退。保留显式 `--data-session-reuse off` 作为临时兼容入口，并在 summary 标记 legacy，待门禁完成后单独删除 V1 代码。
5. 补充统一结构化 summary/event 和单元、loopback、TLS、checksum、resume、取消/断线/冲突回归，记录 actual mode、fallback/拒绝原因、integrity、checkpoint 状态。
