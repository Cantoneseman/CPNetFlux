## 目标与范围

把 2026-10-10 桌面端草案提升为后端/UI 可实现、机器可校验的 API 2.0.0：协议版本握手；V1/V2 分模式能力；用户请求 policy 与后端有效 policy 分离；stable attempt/file/range identity；身份绑定的文件/range/attempt 固定快照分页及事件 watermark；range/checksum 明细；取消 quiescence 屏障和安全 resume 规则。新增冻结 schema、语义校验、正反向合同向量，并明确 agent/backend 当前实现差距。完成后向指定桌面端既有对话交接 `AGENT-BACKEND-02`。

## 验收标准

- UI 可先以 `agent.getInfo` 严格核对 API 2.0.0；未知版本拒绝继续。
- capability 结果按 V1/V2 分开；task 的有效 mode/scheduler/range/checksum/resume/TLS/通道值必须是 backend readback，不得由请求值猜测。
- attempt/file/range 页返回固定快照、agent epoch、revision、sequence watermark、绑定身份的 opaque cursor；过期和错配显式拒绝。
- cancel 只有 backend quiescent 且最终状态持久化后才进入 cancelled；resume 核对 checkpoint/source/policy/manifest/range 身份并创建新 attempt。
- 离线合同覆盖有效/无效 JSON 和跨字段语义；桌面端 prompt 已发送给既有 thread `01a12494-38a8-7fc2-85bc-049336d8ddef`。
