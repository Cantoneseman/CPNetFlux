# 03 使用说明

## 单文件上传

启动 server：

```bash
mkdir -p /tmp/gridflux-root
./build/gridflux-gridftp-server --host 0.0.0.0 --port 2121 --root /tmp/gridflux-root
```

客户端上传：

```bash
./build/gridflux-file-client \
  --host 127.0.0.1 \
  --port 2121 \
  --source /path/to/local.bin \
  --dest /remote.bin \
  --connections 4 \
  --checksum crc32c
```

## 单文件下载

```bash
./build/gridflux-file-download-client \
  --host 127.0.0.1 \
  --port 2121 \
  --source /remote.bin \
  --output /tmp/downloaded.bin \
  --connections 4 \
  --checksum crc32c
```

## 单文件断点续传

首次中断传输会留下 manifest 和 transfer id。恢复时使用：

```bash
./build/gridflux-file-client \
  --host 127.0.0.1 \
  --port 2121 \
  --source /path/to/local.bin \
  --dest /remote.bin \
  --resume \
  --transfer-id <transfer_id>
```

下载恢复同理：

```bash
./build/gridflux-file-download-client \
  --host 127.0.0.1 \
  --port 2121 \
  --source /remote.bin \
  --output /tmp/downloaded.bin \
  --resume \
  --transfer-id <transfer_id>
```

## 目录上传

```bash
./build/gridflux-tree-upload-client \
  --host 127.0.0.1 \
  --port 2121 \
  --source-dir /path/to/source-dir \
  --dest-dir /remote-dir \
  --connections 4 \
  --file-parallelism 4 \
  --checksum crc32c \
  --json-summary /tmp/tree-upload-summary.json
```

## Token 模式

server：

```bash
./build/gridflux-gridftp-server \
  --host 0.0.0.0 \
  --port 2121 \
  --root /tmp/gridflux-root \
  --auth-mode token \
  --auth-token-file /tmp/gridflux.token
```

client 侧传 token 文件：

```bash
./build/gridflux-tree-upload-client \
  --host 127.0.0.1 \
  --port 2121 \
  --source-dir /path/to/source-dir \
  --dest-dir /remote-dir \
  --auth-mode token \
  --auth-token-file /tmp/gridflux.token
```

## TLS 模式

control-plane TLS：

```bash
./build/gridflux-tree-upload-client \
  --host 127.0.0.1 \
  --port 2121 \
  --source-dir /path/to/source-dir \
  --dest-dir /remote-dir \
  --tls-mode required \
  --tls-ca-file /tmp/gridflux.crt
```

control-plane + STOR/RETR data TLS：

```bash
./build/gridflux-tree-upload-client \
  --host 127.0.0.1 \
  --port 2121 \
  --source-dir /path/to/source-dir \
  --dest-dir /remote-dir \
  --tls-mode required \
  --data-tls-mode required \
  --tls-ca-file /tmp/gridflux.crt
```

## Demo

生成 demo 数据：

```bash
python3 tools/demo/make_demo_dataset.py --output /tmp/gridflux-demo --profile small --seed 1
```

运行本地 demo：

```bash
python3 tools/demo/run_alpha_demo.py \
  --mode local \
  --build-dir build \
  --json-output /tmp/gridflux-alpha-demo.json
```

## 事件日志

支持 opt-in JSONL event log：

```bash
./build/gridflux-gridftp-server \
  --host 0.0.0.0 \
  --port 2121 \
  --root /tmp/gridflux-root \
  --event-log /tmp/gridflux-server-events.jsonl
```

事件日志不会记录 token、密码或证书私钥。
