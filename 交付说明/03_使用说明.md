# 03 使用说明

## 单文件上传

启动 server：

```bash
mkdir -p /tmp/cpnetflux-root
./build/cpnetflux-gridftp-server \
  --host 0.0.0.0 \
  --port 2121 \
  --data-port-base 20300 \
  --root /tmp/cpnetflux-root
```

客户端上传：

```bash
./build/cpnetflux-file-client \
  --host 127.0.0.1 \
  --port 2121 \
  --source /path/to/local.bin \
  --dest /remote.bin \
  --connections 4 \
  --checksum crc32c
```

## 单文件下载

```bash
./build/cpnetflux-file-download-client \
  --host 127.0.0.1 \
  --port 2121 \
  --source /remote.bin \
  --output /tmp/downloaded.bin \
  --connections 4 \
  --checksum crc32c
```

## 单文件断点续传

首次中断传输会留下 manifest 和 transfer id。恢复时使用：

```bash
./build/cpnetflux-file-client \
  --host 127.0.0.1 \
  --port 2121 \
  --source /path/to/local.bin \
  --dest /remote.bin \
  --resume \
  --transfer-id <transfer_id>
```

下载恢复同理：

```bash
./build/cpnetflux-file-download-client \
  --host 127.0.0.1 \
  --port 2121 \
  --source /remote.bin \
  --output /tmp/downloaded.bin \
  --resume \
  --transfer-id <transfer_id>
```

## Token 模式

server：

```bash
./build/cpnetflux-gridftp-server \
  --host 0.0.0.0 \
  --port 2121 \
  --root /tmp/cpnetflux-root \
  --auth-mode token \
  --auth-token-file /tmp/cpnetflux.token
```

client 侧传 token 文件：

```bash
./build/cpnetflux-tree-upload-client \
  --host 127.0.0.1 \
  --port 2121 \
  --source-dir /path/to/source-dir \
  --dest-dir /remote-dir \
  --auth-mode token \
  --auth-token-file /tmp/cpnetflux.token
```

## TLS 模式

control-plane TLS：

```bash
./build/cpnetflux-tree-upload-client \
  --host 127.0.0.1 \
  --port 2121 \
  --source-dir /path/to/source-dir \
  --dest-dir /remote-dir \
  --tls-mode required \
  --tls-ca-file /tmp/cpnetflux.crt
```

control-plane + STOR/RETR data TLS：

```bash
./build/cpnetflux-tree-upload-client \
  --host 127.0.0.1 \
  --port 2121 \
  --source-dir /path/to/source-dir \
  --dest-dir /remote-dir \
  --tls-mode required \
  --data-tls-mode required \
  --tls-ca-file /tmp/cpnetflux.crt
```

## 事件日志

支持 opt-in JSONL event log：

```bash
./build/cpnetflux-gridftp-server \
  --host 0.0.0.0 \
  --port 2121 \
  --data-port-base 20300 \
  --root /tmp/cpnetflux-root \
  --event-log /tmp/cpnetflux-server-events.jsonl
```

事件日志不会记录 token、密码或证书私钥。

补充：`EPSV` 数据连接不是单端口。部署到公网时，安全组/防火墙/SSH
转发必须同时覆盖 `--data-port-base` 到 `--data-port-base + 511`，并且客户端
要按 EPSV 返回值建立真实数据连接，不能只拿一个 `-L` 端口转发结果当作验证。
