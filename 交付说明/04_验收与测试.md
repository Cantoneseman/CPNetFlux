# 04 验收与测试

## Alpha RC 标准验收

Debug 完整测试：

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build -j"$(nproc)"
ctest --test-dir build --output-on-failure
```

Release + io_uring 测试：

```bash
cmake -S . -B build-io-uring-real -DCMAKE_BUILD_TYPE=Release -DCPNETFLUX_ENABLE_IO_URING=ON
cmake --build build-io-uring-real -j"$(nproc)"
ctest --test-dir build-io-uring-real --output-on-failure
```

Alpha RC 验收时，两台机器均为：

```text
181/181 passed
```

## 常用 smoke

只跑 GridFTP/TLS/data TLS 相关：

```bash
ctest --test-dir build -R "gridftp|tls|data_tls" --output-on-failure
```

只跑目录相关：

```bash
ctest --test-dir build -R "tree" --output-on-failure
```

只跑 release helper：

```bash
ctest --test-dir build -R "release|artifact|demo|soak" --output-on-failure
```

## Public hygiene

公开发布前必须跑：

```bash
python3 tools/release/check_public_hygiene.py --path . --strict
```

它会检查：

- 不包含 `AGENTS.md`。
- 不包含 build 产物。
- 不包含明显 token、私钥、密码。
- 不包含已知私网/敏感信息样例。
