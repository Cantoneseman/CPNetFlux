# 02 部署流程

本文说明如何从本地原型包构建和运行 GridFlux Alpha RC。

## 环境要求

推荐环境：

- Linux x86_64。
- GCC 13+。
- CMake 3.24+。
- Python 3.9+。
- OpenSSL development headers。
- 可选：liburing，用于 real io_uring build。

Ubuntu/Debian 示例：

```bash
sudo apt-get update
sudo apt-get install -y build-essential cmake python3 python3-venv pkg-config libssl-dev liburing-dev
```

## 获取代码

如果从本地交付包复制到 Linux：

```bash
cd /root/projects
cp -a /path/to/GridFlux-Alpha-RC-20260519 GridFlux
cd GridFlux
```

如果从 GitHub 获取公开脱敏版本：

```bash
git clone https://github.com/Cantoneseman/GirdFlux.git GridFlux
cd GridFlux
```

## Debug 构建

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build -j"$(nproc)"
```

运行完整测试：

```bash
ctest --test-dir build --output-on-failure
```

Alpha RC 对应验收结果为 `181/181 passed`。

## Release + io_uring 构建

如果系统安装了 liburing：

```bash
cmake -S . -B build-io-uring-real -DCMAKE_BUILD_TYPE=Release -DGRIDFLUX_ENABLE_IO_URING=ON
cmake --build build-io-uring-real -j"$(nproc)"
ctest --test-dir build-io-uring-real --output-on-failure
```

验证 real io_uring smoke：

```bash
ctest --test-dir build-io-uring-real -R FileIoTest.IoUringContextReadWriteSmokeWhenAvailable --output-on-failure -V
```

## 双机部署建议

推荐结构：

```text
机器一：运行 gridflux-gridftp-server
机器二：运行 file/tree client、private smoke、release gate
```

两台机器之间建议有私网连通。不要把密码、token、私钥写入文档或 Git。

## 启动 GridFTP-like server

示例：

```bash
mkdir -p /tmp/gridflux-root
./build/gridflux-gridftp-server \
  --host 0.0.0.0 \
  --port 2121 \
  --root /tmp/gridflux-root
```

## Token auth 示例

生成 token 文件：

```bash
printf '%s\n' 'replace-with-your-token' > /tmp/gridflux.token
chmod 600 /tmp/gridflux.token
```

启动：

```bash
./build/gridflux-gridftp-server \
  --host 0.0.0.0 \
  --port 2121 \
  --root /tmp/gridflux-root \
  --auth-mode token \
  --auth-token-file /tmp/gridflux.token
```

## TLS 示例

生成临时自签证书，仅用于测试：

```bash
openssl req -x509 -newkey rsa:2048 -nodes \
  -keyout /tmp/gridflux.key \
  -out /tmp/gridflux.crt \
  -subj "/CN=gridflux-alpha" \
  -days 1
chmod 600 /tmp/gridflux.key
```

启动 control-plane TLS：

```bash
./build/gridflux-gridftp-server \
  --host 0.0.0.0 \
  --port 2121 \
  --root /tmp/gridflux-root \
  --tls-mode required \
  --tls-cert-file /tmp/gridflux.crt \
  --tls-key-file /tmp/gridflux.key
```

启动 control-plane + STOR/RETR data TLS：

```bash
./build/gridflux-gridftp-server \
  --host 0.0.0.0 \
  --port 2121 \
  --root /tmp/gridflux-root \
  --tls-mode required \
  --data-tls-mode required \
  --tls-cert-file /tmp/gridflux.crt \
  --tls-key-file /tmp/gridflux.key
```

注意：Phase 6D/6E 中 data TLS 只保护 STOR/RETR framed file data channel，不保护 LIST/NLST listing data channel。
